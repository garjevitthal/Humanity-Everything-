LifeGuard AI — Version 1.0
Creators: Vitthal Garje & ChatGPT (OpenAI)

HOW TO USE
1. Open index.html in a modern browser on a phone or computer.
2. The emergency button opens the device dialer for India's 112 emergency number.
3. A trusted contact number can be saved in the browser on that device and an SMS draft can be prepared.

IMPORTANT
- This is a demonstration prototype, not a certified emergency-response service.
- It does not automatically send alerts, track location, monitor health, or guarantee delivery.
- Test the interface without placing a real emergency call.
- Do not use it to incapacitate or harm anyone.

PUBLISHING
Upload index.html to a static website host (for example, GitHub Pages or Netlify) to make it available online.
No website has been published by this package itself.
