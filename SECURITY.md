 Security Policy

Project Status

LifeGuard AI is currently a prototype. It is not an emergency-response service or a medical device. It does not provide automatic monitoring, location tracking, automatic messaging, medical diagnosis, or guaranteed assistance.

In India, contact emergency services directly at 112 in an emergency.

Supported Versions

Security fixes are considered for the latest code on the "main" branch on a best-effort basis.

Version| Support
Latest "main" branch| Best effort
Older versions and builds| No guarantee

Reporting a Vulnerability

Please report suspected security vulnerabilities privately.

1. Check the repository's Security tab for GitHub's Report a vulnerability option, if available.
2. If private reporting is unavailable, contact the maintainer privately through: https://github.com/garjevitthal
3. Include the affected component, steps to reproduce in an authorized test environment, potential impact, and relevant version or commit.

Do not publish exploit details, passwords, access tokens, or personal information in public issues or discussions.

Do not access or modify other people's data, disrupt services, or test systems without permission.

Response Process

Reports will be reviewed on a best-effort basis. The maintainer may request more information. There is no guaranteed response or resolution time.

Please allow time for investigation and a possible fix before publicly disclosing vulnerability details.

Scope and Limitations

LifeGuard AI currently includes a website prototype, Android build artifacts, and a basic backend.

A successful build or website deployment does not mean the project has passed a security audit or is ready for production use.

For ordinary bugs and feature requests, please use the repository's normal issue process.
